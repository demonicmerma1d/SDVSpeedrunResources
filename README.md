Some basic utility guides for getting started with SDV speedrunning.

- [How to setup a load remover in LiveSplit](./loadremover.md)
- [Downpatching to a specific version](./downpatching.md)

Additionally, contains some information on [glitches](./glitches/), along with [routes](./routes/) and [pastes](./routes/Pastes/) to some glitched speedruns.

## Specific setup instructions
- To utilise the [Name Compiler](/glitchResources/FormatGlitchedNames.py), locally add a file called `PathToFile.txt` inside `glitchResources`. This file is to specify the filepath to what you want to compile for injection locally, without updating on commits and syncing.
