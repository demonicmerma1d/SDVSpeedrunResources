# Route
## Notes
- Version 1.6
- Chinese
- Female
- Remixed bundles

## Overview
The goal of this run is to complete the Fishtank(autosplit available), the third room in the Community Center. Time starts on pressing ok for a fresh file, and ends on the white flash of room completion. 

### File Creation and Introduction
Name the player the text in the paste.
Watch the introduction until Robin starts saying the name, then click the skip cutscene button. 

### Day 1
1) Drink the triple shot expresso you have been given.
2) Read the mail once(note: with this exact paste you must read it before 6:20am)
3) Run to Pierre's and buy the first backpack upgrade, then return scepter home.
4) Read the mail again(it should be 6:20am by this point in time, this is important), then run to the Community Center to turn your items in.
5) Turn the summer foraging bundle into the Crafts Room(yellow, bottom left) then exit the menu.
6) [Animation Cancel](/Animation%20Cancelling.md) to regain control, and walk to the Fishtank while it opens up.
7) Turn in all the Fishtank items, starting with the center bundle. This is the only one which will be remixed in the room, the desired bundle is quality fish, if you do not have quality fish, reset(this is a 1/3 rng check).  

- It would be slightly faster to go for sticky bundle to open the community centre up instead of summer forage, however this is an extra 1/3 rng check.
