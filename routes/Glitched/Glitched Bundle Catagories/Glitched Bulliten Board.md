# Route
## Notes
- Version 1.6
- Chinese
- Female
- Standard bundles.

## Overview
The goal of this run is to complete the Bulliten Board(autosplit available), which is unlocked after 3 bundles inside the Community Center. Time starts on pressing ok for a fresh file, and ends on the white flash of room completion. 

### File Creation and Introduction
Name the player the text in the paste.
Watch the introduction until Robin starts saying the name(press ESC 2x to skip the start), then click the skip cutscene button. With the current paste the cutscene should [crash](/glitches/Miscellaneous%20Glitches) and autoend.

### Day 1
1) Drink the triple shot expresso and eat the magic rock candy you have been given.
2) Go outside and read the mail once.
4) Run to Pierre's and buy both backpack upgrades, then return scepter home.
5) Read the mail again then run to the Community Center to turn your items in.
6) At the crafts room, turn in the spring, summer and winter foraging bundles. 
7) [Animation Cancel](/Animation%20Cancelling.md) to regain control run to where the bulliten board plaque would appear, Animation cancelling to main control where necessary.
8) Click on the location where the bulliten board appears(you do not need to wait for the plaque to appear), and turn the bulliten board items in.
