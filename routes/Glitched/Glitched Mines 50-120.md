# Route
## Notes
- Version 1.6
- Chinese
- Female

## Overview
The goal of this run is to reach floor 50/120 in the mines. Time starts on pressing ok, and ends when you reach floor 50/120(autosplit available).

### File Creation and Introduction
Name the player the text in the paste.
Watch the introduction until Robin starts saying the player name(press ESC 2x to skip the start), and then the cutscene will autoend on a crash. 

### Day 1
1) Go outside and read the mail once.
2) Use mountain warp totem to get to the mountain.
3) Run into the mines and interact with the elevator to go to floor 50/120.
