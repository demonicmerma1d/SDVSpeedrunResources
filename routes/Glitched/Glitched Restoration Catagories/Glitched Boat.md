# Route
## Notes
- Version 1.6
- Chinese
- Female

## Overview
The goal of this run is to complete and ride the boat to ginger island. Time starts on pressing ok, and ends when you buy a ticket for the boat(manual split).

### File Creation and Introduction
Name the player the text in the paste.
Watch the introduction until Robin starts saying the name(press ESC 2x to skip the start), and then the cutscene will autoend on a [crash](/glitches/Miscellaneous%20Glitches). 

### Day 1
1) Go outside and read the mail once.
2) Use the island warp to get to Ginger Island
3) Run down back to the boat, return to the mainland, and buy a ticket for the boat.
