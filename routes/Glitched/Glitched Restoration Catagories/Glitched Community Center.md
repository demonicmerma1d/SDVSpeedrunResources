# Route
## Notes
- Version 1.6
- Chinese
- Female

## Overview
The goal of this run is to complete the Community Center. Time starts on pressing ok, and ends on the room flash of the final bundle in the Community Center. For this route in particular, we know that the final room will be the boiler room, so it is recommended to use the boiler room autosplit instead of the Community Center autosplit for reliablity.

## The Run

### File Creation and Introduction
Name the player the text in the paste.
Watch the introduction until Robin starts saying the name(press ESC 2x to skip the start), at which point the cutscene [crashes](/glitches/Miscellaneous%20Glitches) automatically skipping it.

### Mail Read 1
- Eat the two speed buffs you have been given(triple shot expresso and magic rock candy).
- Go outside to the mailbox, and read the mail **one** time.
- Run to Pierre's and buy both backpack upgrades.
- Use the return scepter to teleport home.

### Mail Read 2
- Read the mail once.
- Run to the Community Center and head towards the Crafts room to start donating.
- Here you have a few options for when to start the animations as you turn the crafts room items in by exiting out, [Animation Cancelling](/Animation%20Cancelling.md) for control and reentering the menu to finish donating.
    - After 1 bundle - This garentees that the opening animations will be clear by the time you are finished turning in your current items and has no risk of softlocking the game(specifically, going through a transition as the game opens a room). It does involve learning blind movement between the Crafts Room and the Pantry which to be consistent, is a little slower.
    - After 5 bundles - This enables you to have vision while walking to the Pantry, so you can take a faster path, however you risk softlocking if you screen transition slightly later. You also have to blind path through town back to the Community Center, however this is the same path as you would take with vision and not a slower version.
- After finishing the crafts room, walk to the pantry, and turn in the remaining items you have for there, leave the menu, Animation Cancel for control and return scepter home.

### Mail Read 3
- Read the mail once.
- Run back to the Community Center, and try not to softlock.
- Starting at the Fishtank, turn in every single fish, leave the menu and Animation Cancel for control.
- Run to the Pantry and turn in the remaining items, finishing it.
- Animation Cancel for control, and return scepter home.

### Mail Read 4
- Read the mail once.
- Run back to the Community Center.
- Starting at the Bulliten Board, turn all the items in.
- Animation Cancel for control, run up to the Vault and buy all 4 bundles.
- Animation Cancel for control and run to the Boiler Room(slightly blind) and turn the remaining items in.  

## Blind movement notes
### Normalised Crafts Room -> Pantry
- Hold up to get out of the Crafts Room.
- Hold right+up to navigate up to near the topright corner of the room.
- Hold left for a bit and right click.

### House -> Community Center
- Hold right through busstop until you are in town.
- Through town will be the same movement you make with sight, which is a combination of holding right into up-right then some up.
- More up-right movement at which point the camera returns to you.
Through this movement you will have to occessionally Animation Cancel to regain control.
