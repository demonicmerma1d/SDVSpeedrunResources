# Route

## Notes
- Version 1.2(or earlier, just use 1.2).
- Any gender(if you use the female character you can replace the 1st character of the paste with `¦`, but this is entirely irrelevent).
- Any Farm type.
- Chinese.

## Overview
The goal of this run is to complete the joja route as fast as possible using glitches, timing starts on file creation pressing the ok button, and ends when the player holds the joja cola machine above their head.

## The Run
### File Creation and Introduction
Name the player the text in the paste.
Watch the introduction until Robin starts saying the name(press ESC 2x to skip the start), [WSC](/glitches/Window%20Shift%20Cancel.md) when the dialogue box starts, close the menu and press F to skip the cutscene, then [save skip](/glitches/Miscellaneous%20Glitches.md) for timesave.

### Day 1
1) Use a beach warp totem as soon as you are able to.
2) After you teleport, open the journal using the button in the top right of the HUD and close the menu to get early control([Journal Control](/glitches/Miscellaneous%20Glitches.md)). (alteratively you can WSC again here)
3) Enter town and watch the cutscene, WSCing and mashing through every dialogue box as it appears. Tthere is a dialogue box immeadietly after walking through the transition to be prepared for.
