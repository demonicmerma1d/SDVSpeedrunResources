# Route
## Notes
- Version 1.6
- Chinese
- Female

## Overview
The goal of this run is to complete the missing bundle inside abandoned jojamart. Time starts on pressing ok, and ends when the cutscene after completing the bundle starts(manual split).

### File Creation and Introduction
Name the player the text in the paste.
Watch the introduction until Robin starts saying the name(press ESC 2x to skip the start), and then the cutscene will autoend on a [crash](/glitches/Miscellaneous%20Glitches). 

### Day 1
1) Go outside and read the mail once.
2) Run to the minecarts in the busstop and go to town(the top option in the menu).
3) Go up to jojamart, go inside and complete the bundle.
